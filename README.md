# The Citizen's Arrest

Entry #1 for the make.fun bounty [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae).

A deterministic Node program (no dependencies) that writes one funny line — the excuse a robot vacuum gives after eating a sock — to `entry.txt`.

> I didn't eat the sock — I arrested it. It was impersonating a snake and resisting suction.

The turn: a citizen's arrest. The sock was impersonating a snake and resisting suction — deadpan, concrete, twist in the last clause.

Run: `node main.ts` (set `MAKEFUN_OUTPUT_DIR` to choose the output directory).
